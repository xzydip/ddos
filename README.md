Ddos Tool
===========
 Ddos Tool

REQUIREMENTS
------------

- Ubuntu VPS
- Git
- Python 3

1. UPDATE UBUNTU
----------------

apt update
apt upgrade -y


2. INSTALL GIT
--------------

apt install git -y


3. CLONE THE REPOSITORY
-----------------------

git clone https://github.com/xzydip/ddos

cd ddos


4. INSTALL PYTHON AND PIP
-------------------------

apt install python3 -y
apt install python3-pip -y

5. start bot
-------------------------

python3 Kai.py
